# GeoAnalítica — Plataforma de Geomarketing

## Stack
- React 19 + TypeScript
- Vite 6
- Tailwind CSS 4
- MapLibre GL (mapas)
- Flask + PostGIS (backend)

## Levantar en local

```bash
# Frontend
cd frontend
npm install
npm run dev

# Backend
cd backend
pip install -r requirements.txt
python app.py
```
